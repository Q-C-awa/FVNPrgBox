# QC's Free Publish Galgame program packages
* 这里是浅唱的免费gal程序公开仓库
* Mainly used for writing free UI program packages for the Ren'Py engine
* 主要用于编写一些免费的UI的Ren'py程序包
# How to use？
* 如何使用？
* You can simply copy the files from this repository into your Ren'Py engine project folder and use them directly
* 你可以复制这个仓库的文件到你的Ren'py引擎项目文件夹中即可使用
* Or you can download the already-packaged program bundles from Releases
* 或者你下载Releases中已经打包好的程序包
* You are free to study the code or modify it as you like
* 你可以随意修改学习或者修改其中的代码
* You may use the code of this package in commercial or free game development
* 你可以将这个程序包的代码用于商业或者免费游戏制作中
